Grass Assets - separated PNG crops

This ZIP contains transparent PNG crops extracted from the supplied grass/foliage reference sheet.
Each numbered PNG is a separate crop. The contact sheet preview helps identify the files.

Important:
- These are cropped visual assets, not a calibrated 32x32 Godot TileSet.
- The original art's pixel scale and crop dimensions vary.
- Ground patches may be larger than one tile; resize or slice them in your pixel editor if needed.
- Check the assets in Godot before using them in production.
